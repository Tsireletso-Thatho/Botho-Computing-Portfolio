## 🎯 Overview

**MarketPulse Analytics** is a real-time financial dashboard built as part of my **Web Design and Development (WDD) module**.  

This project demonstrates modern frontend development techniques including:

- Dynamic DOM manipulation  
- Data visualization  
- Responsive design  
- User preference management  

### 🌐 Live Demo

🔗 [Launch MarketPulse Analytics](https://tsireletso-thatho.github.io/Botho-Computing-Portfolio/marketpulse-analytics/)

---

## ✨ Features

### 📈 Real-Time Data Visualization

- Live line chart updating every 3 seconds  
- Asset allocation chart (doughnut, pie, polar area toggle)  
- Multi-asset comparison  
- Customizable time ranges (1D, 1W, 1M, 1Y)  

### 🎨 Professional UI/UX

- Dark/Light mode toggle  
- Glassmorphism design  
- Fully responsive layout  
- Smooth animations and transitions  

### ⚙️ User Customization

- Asset selection (Gold, NASDAQ, S&P 500, BTC, ETH, AAPL, TSLA, MSFT, etc.)  
- Custom watchlist with add/remove functionality  
- Chart type switching (Line, Bar, Area)  
- Persistent settings using `localStorage`  

### 🧭 Multi-Section Navigation

- Dashboard  
- Markets  
- Portfolio  
- Alerts  
- Settings
